## 🚀 Featured Projects

### 🏎️ [ApexGrid — F1 Race Ticket Booking Platform](https://github.com/a1fariz/ApexGrid)
A production-ready microservices application featuring 3 independent Spring Boot services, real-time ticket quota management via PostgreSQL triggers, JWT-based security with Role-Based Access Control, and a premium React glassmorphism dashboard.
- 🛠️ **Microservices Architecture** — User Service, Race Service, and API Gateway via Spring Cloud Gateway.
- ⚡ **Real-Time Quota & Scheduler** — 30-minute auto-expiry reservation scheduler and transactional PostgreSQL triggers.
- 📊 **Admin Analytics Dashboard** — Full CRUD management & real-time analytics using database views.

`Spring Boot 3.2` `Spring Cloud Gateway` `React 18` `PostgreSQL` `Docker` `JWT` `TailwindCSS`

### 🧠 [StudyMate AI — Intelligent RAG-Based Study Assistant](https://github.com/a1fariz/StudyMateAI)
A high-performance asynchronous RAG (Retrieval-Augmented Generation) pipeline for parsing textbook PDFs and generating personalized study content using Google Gemini 2.0 Flash.
- 🔍 **Semantic Search** — Vector database index using ChromaDB and sentence-transformers.
- 💡 **AI Orchestration & Citations** — Auto-generated flashcards, custom quizzes, dynamic study plans, and page-specific citations via PyMuPDF.
- 🛡️ **Production-Ready Core** — Asynchronous rate limiters, bcrypt JWT auth, Docker Compose, and automated CI/CD via GitHub Actions.

`Python` `LangChain` `ChromaDB` `Gemini 2.0 Flash` `Docker` `GitHub Actions`

### 📊 [Finance Feasibility — AI-Powered Investment Analysis Platform](https://github.com/a1fariz/finance-feasibility) | [Live Demo](https://finance-feasibility.alfarizi.my.id/)
A full-stack, AI-powered web application for conducting financial feasibility studies and investment analysis, with real-time calculations and Gemini-powered professional insights.
- 📈 **Financial Engine** — Automatic calculations for Net Present Value (NPV), Internal Rate of Return (IRR), Return on Investment (ROI), and Break-even Payback.
- 🤖 **AI Strategic Insights** — Built with Gemini 3.5 Flash to generate executive-level reports, risk assessments, and recommendations.
- 🔒 **Secure Auth & PDF Export** — Firebase Google Sign-In and direct PDF report downloads.

`React 19` `Node.js` `Express` `PostgreSQL (Supabase)` `Drizzle ORM` `Firebase Auth` `Gemini AI` `TailwindCSS`
