## Featured Projects

### [ReLoop — Enterprise Circular Commerce Platform](https://github.com/a1fariz/ReLoop) | [Live Demo](https://reloop.biz.id)

Enterprise-grade circular commerce platform built as a Quarkus 3.15 LTS modular monolith across 25 bounded contexts. Features balanced double-entry financial escrow accounting (zero discrepancy), 15-minute anti-hoarding checkout leases with pessimistic row locking (`SELECT ... FOR UPDATE`), 50-point technical grading certification, and transactional outbox event dispatching.

- **Tech Stack**: `Java 17` `Quarkus 3.15 LTS` `Next.js 14` `PostgreSQL 16` `Redis 7` `Flyway` `Testcontainers`

---

### [ApexGrid — F1 Race Ticket Booking Platform](https://github.com/a1fariz/ApexGrid)

Production-ready distributed microservices system featuring 3 independent Spring Boot services (Gateway, User Service, Race Service) coordinated via Spring Cloud Gateway. Includes real-time race ticket inventory synchronization via PostgreSQL transactional triggers, an automated 30-minute reservation expiry scheduler, stateless JWT RBAC security, and a React glassmorphism dashboard.

- **Tech Stack**: `Java 17` `Spring Boot 3.2` `Spring Cloud Gateway` `React 18` `PostgreSQL 16` `Docker Compose` `JWT`

---

### [StudyMate AI — Asynchronous RAG Study Assistant](https://github.com/a1fariz/StudyMateAI)

Asynchronous Retrieval-Augmented Generation (RAG) pipeline for processing academic textbook PDFs and generating verified study materials. Built with FastAPI, PyMuPDF citation extraction, LangChain splitters, ChromaDB cosine vector search, Google Gemini 2.0 Flash prompt orchestration, token-bucket rate limiting (60 req/min), and automated CI/CD via GitHub Actions.

- **Tech Stack**: `Python 3.12` `FastAPI` `LangChain` `ChromaDB` `Gemini 2.0 Flash` `Docker` `Pytest`

---

- **Tech Stack**: `React 19` `Vite` `Tailwind CSS` `React Router 7` `Framer Motion` `Web Audio API` `The Met API`
